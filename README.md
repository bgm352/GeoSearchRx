# GeoSearch Health Insights

GeoSearch Health Insights is a Streamlit web app that combines first-party and third-party SEO data sources (Google Search Console, Google Trends, SEMrush) with AI-powered insights (OpenAI, Gemini) to deliver actionable, geo-targeted search intelligence for health systems and marketers.

## Features

- **API Key Input:** Securely enter your OpenAI, Gemini, SEMrush, and Google Search Console credentials in the sidebar.
- **Data Aggregation:** Pulls and merges live data from Google Trends, Google Search Console, and SEMrush.
- **Geo and Keyword Filtering:** Analyze search trends and performance by geography and keyword.
- **AI Insights:** Uses OpenAI and Gemini to generate recommendations and identify market opportunities.
- **Interactive Dashboard:** View, filter, and download your SEO data and AI-generated insights.
